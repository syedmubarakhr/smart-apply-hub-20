# Applicant Ally

Build a modern enterprise SaaS web application called SATS (Smart Applicant Tracking System).

Technology Stack:

- React

- TypeScript

- Tailwind CSS

- Supabase

- PostgreSQL

Design Style:

- Premium enterprise UI

- White, Blue and Orange theme

- Glassmorphism cards

- Responsive

- Professional animations

- Sidebar + Top Navigation

- Reusable components

Create the project structure only.

Create these pages:

1. Landing Page

2. Developer Login

3. Company Login

4. Employee Login

5. Face Registration

6. Face Verification

7. Developer Dashboard (empty layout)

8. Company Dashboard (empty layout)

Create routing between all pages.

Create a responsive sidebar and header.

Do not add business logic yet.

Use Supabase authentication placeholders.

Make the UI production quality.
